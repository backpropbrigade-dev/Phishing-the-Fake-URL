# Website Redesign Plan - Academic Journal Style

## Current vs. Desired Design

### Current Design
- Modern app-style interface
- Colorful gradients and animations
- Dashboard-focused
- Card-based layouts
- Navy blue theme

### Desired Design (Academic Journal Style)
- Professional, formal appearance
- Clean white backgrounds
- Structured, content-focused
- Traditional layouts
- Academic color scheme (blues, grays, whites)

## Key Changes Needed

### 1. **Overall Layout**
- [ ] Remove animated backgrounds
- [ ] Simplify color scheme to white/light gray/blue
- [ ] Add traditional header with logo and navigation
- [ ] Create footer with contact info and links
- [ ] Use more whitespace and breathing room

### 2. **Typography**
- [ ] Use serif fonts for headings (Georgia, Times New Roman)

- [ ] Secondary: Light Gray (#f5f5f5)

### 4. **Navigation**

### 5. **Login Page**

### 6. **Dashboard Redesign**
