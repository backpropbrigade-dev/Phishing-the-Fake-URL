# 🎓 Student Learning Analytics Platform (SLAP)

An AI-powered early-warning system that monitors student learning behavior to identify conceptual decline before it impacts academic performance.

## ✨ Features

### 🔐 Multi-Role Authentication
- **Admin**: Full system access with user management
- **Faculty**: Student monitoring, test creation, analytics
- **Student**: Performance tracking, test taking, feedback

### 📊 Real-Time Analytics
- Drift score calculation and monitoring
- Performance trend visualization
- Behavioral pattern analysis
- Early warning alerts

### 👥 User Management
- Create and manage student accounts
- Create and manage faculty accounts
- Department-based organization
- Role-based access control

### 📝 Test Management
- Create tests with difficulty levels (Easy/Medium/Hard)
- Automatic grading system
- Test result tracking
- Performance analytics

### 🎯 Drift Detection
- AI-powered learning pattern analysis
- Early identification of struggling students
- Automated alert generation
- Personalized feedback recommendations

### 💼 Professional Features
- Toast notifications for user actions
- Loading states and spinners
- Password strength indicators
- Form validation with real-time feedback
- Confirmation dialogs for critical actions
- Responsive design for all devices

## 🚀 Quick Start

### Option 1: Direct Access
Simply open the [live demo](https://thirumalasettyharshinipriya-crypto.github.io/student-learning-analytics-platform/) in your browser!

### Option 2: Local Development
```bash
# Clone the repository
git clone https://github.com/thirumalasettyharshinipriya-crypto/student-learning-analytics-platform.git

# Navigate to the project folder
cd student-learning-analytics-platform

# Open in browser
# Simply double-click index.html or use a local server
python -m http.server 8000
# Then visit http://localhost:8000
```
